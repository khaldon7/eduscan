# EduScan

تطبيق أندرويد يحوّل صفحة الدرس المطبوعة (صورة من الكاميرا أو المعرض) إلى شاشة تفاعلية: نقاط ساخنة فوق الرسوم والمصطلحات، شروح، واختبار قصير. يُحفظ الدرس محلياً ليعمل بدون إنترنت.

## المعمارية
- **التطبيق (Android / Kotlin / Jetpack Compose):** واجهة، تخزين محلي (Room)، عرض الشاشة التفاعلية.
- **الخادم الوسيط (FastAPI):** يستقبل الصورة ويرسلها إلى Claude مع مفتاح API. المفتاح لا يوضع في التطبيق أبداً.
- **الذكاء الاصطناعي (Claude Vision):** يقرأ الصفحة ويعيد JSON فيه الشرح والنقاط الساخنة (إحداثيات نسبية 0..1) والاختبار.
- **ML Kit OCR:** استخراج نص إنجليزي/لاتيني على الجهاز. ملاحظة: ML Kit لا يدعم العربية، لذلك يتولى Claude قراءة النص العربي.

## تدفق البيانات
الكاميرا/المعرض ← تصغير الصورة ← الخادم ← Claude ← JSON ← Room + ملف الصورة محلياً ← شاشة الدرس

## الإعداد
1. افتح المجلد `eduscan` في Android Studio (Hedgehog أو أحدث).
2. عدّل `BASE_URL` في `app/build.gradle.kts` إلى عنوان الخادم.
3. شغّل الخادم:
```
cd backend
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_key
uvicorn main:app --host 0.0.0.0 --port 8000
```
4. شغّل التطبيق على الهاتف أو المحاكي.

## ملاحظات أمنية
- لا تضع مفتاح API في التطبيق. أي مفتاح داخل APK يمكن استخراجه.
- أضف مصادقة بسيطة (رمز لكل مستخدم) وحدّاً لعدد الطلبات على الخادم قبل النشر.

## الخطوات التالية المقترحة
1. استبدال المعرض بـ CameraX لمعاينة مباشرة والتقاط أفضل.
2. عرض النقاط الساخنة بشكل دقيق فوق الصورة بحسب نسبة التكبير.
3. تصدير الدرس كـ PDF للحفظ.
